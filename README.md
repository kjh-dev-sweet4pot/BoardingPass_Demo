## 지표 산식

수집 필드: **조회수 · 좋아요 · 댓글수 · 저장수 · 공유수 · 리포스트**. 도달은 수집하지 않는다.

```
참여율(ER)      = (좋아요 + 댓글) / 조회수
CPV             = 노출가 / 조회수
CPE             = 노출가 / (좋아요 + 댓글)
팔로워 대비 배율 = 조회수 / 팔로워
```

배정·캠페인 집계는 콘텐츠별 비율을 평균내지 않고, **원시값을 합산한 뒤** 위 산식을 적용한다.

### 샤오홍슈 조회수 추정

노트 API는 조회수(`view_count`)를 안 주는 경우가 많다. 실측 조회수가 있으면 그대로 쓰고, 없거나 0이면 가정 참여율 5%로 역산한다.

```
가정 ER           = 0.05
추정 조회수       = (좋아요 + 댓글) / 0.05
좋아요·댓글이 0이면  저장수 / 0.05
하한              = 좋아요 + 댓글 + 저장 + 공유
```

인스타그램·틱톡은 수집된 조회수를 그대로 쓴다.
